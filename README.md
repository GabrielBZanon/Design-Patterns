Padrões Arquiteturais

🧠 O que é o Factory?
O Factory Pattern (padrão de fábrica) é um modelo de projeto (design pattern) usado para criar objetos sem expor a lógica de criação diretamente. Em vez de usar new diretamente no seu código toda vez que quiser um objeto, você delega isso para uma "fábrica" (uma função ou classe).

💡 Pense em uma fábrica de pizzas: você escolhe o sabor, e a fábrica sabe como montar e entregar. Você não precisa saber como fazer a massa, molho, etc.
